# Audrey Tang — Sources (provenance)

## Where the data comes from

- **[archive.tw](https://archive.tw)** — Audrey Tang's 30-year public
  transcript archive. The corpus is maintained by the
  [sayit-hono](https://github.com/bestian/sayit-hono) backend and the
  [transcript](https://github.com/audreyt/transcript) source repo.
- **The `sayit-database` D1 instance** — Cloudflare D1 holds the
  `sections` table queried by `npm run skill:mine`.
- **`outputs/voice-metrics.json`** — generated by `scripts/mine-audrey-voice.ts`
  walking every section where `name LIKE '唐鳳%' OR name LIKE 'Audrey Tang%'`
  (her 華語 and English speaker attributions respectively).

## Bilingual coverage

- **Vectorize index `askit-audrey-tang`** (768-dim cosine,
  `@cf/google/embeddinggemma-300m`) covers the **華語 transcripts** — it is
  the retrieval layer for `/cag` when the question contains Han characters.
- **Latin-script questions** (no Han characters) fall back to
  archive.tw full-text search, since the Vectorize index is deliberately
  Chinese-only (see `README.md` "How it works" §Retrieval).
- Her English talks are stored in the same archive with speaker attribution
  `Audrey Tang` (the 華語 versions are `唐鳳`); both are her voice.

## Citation format

`https://archive.tw/<filename>[/<nest_filename>]#s<section_id>`

Matches `buildArchiveTwSectionHref` in `src/utils/search.ts`. Example:
`https://archive.tw/2026-06-10-creative-bureaucracy-award-acceptance-s#s63856799`
resolves to section 1 of her 2026-06-10 Creative Bureaucracy Award acceptance
speech. The same URL works with or without the `#s<id>` fragment (the
fragment scrolls the page to that section).

**Note on search:** `archive.tw/api/search.json` may not match bracketed
phrases like 「數位民主」 — when a known quote fails to surface in search,
fetch the section directly via `/api/section/<section_id>` to confirm it
exists.

## Maintenance

When the archive grows (a sayit-hono deploy adds new transcripts):

```bash
npm run skill:mine
```

re-runs the miner against the current D1 corpus and regenerates
`outputs/voice-metrics.json`. Then refresh the tables in `persona.md` from
the regenerated JSON — the phrase counts and top n-grams update, and the
cited quotes in `spirit.md` / `work.md` remain valid (their section ids are
stable).

If the English branch comes back empty after a mine, `SPEAKER_LIKE_EN`
(default `Audrey Tang%`) likely no longer matches — re-query
`archive.tw/api/search.json` with an English phrase from a recent talk,
read the `speaker` field, and set `SPEAKER_LIKE_EN` accordingly. Do not
change the schema; only the env var.

See `SKILL.md` §3 "What To Load" for the retrieval API shapes used to ground
specific questions.
